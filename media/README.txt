ZOÉ CLINIC — MEDIA FOLDER
=========================

Drop your photos and video clips here using these EXACT filenames.
When a file exists, the page swaps out the placeholder automatically —
no code changes needed. Just refresh the page.

IMAGES  (use .jpg, .png or .webp)
  hero.jpg       -> big hero visual (top of page).  Best ~1000x1100px, portrait.
  team.jpg       -> team / staff photo.             Best ~1000x800px, landscape.

VIDEOS  (use .mp4 — short clips, muted, they autoplay + loop)
  action-1.mp4   -> "Suspension cage therapy (DMI)"
  action-2.mp4   -> "Balance & supported gait"
  action-3.mp4   -> "Play & motor skills"
  action-4.mp4   -> "Occupational therapy for independence"

TIPS
  - Keep videos short (5-15s) and small (< ~8 MB each) so the page loads fast.
    You can trim/compress Instagram clips before adding them.
  - If you want a still image instead of a video for an action slot,
    just name the file action-1.jpg (etc.) and edit the data-media
    attribute in index.html from action-1.mp4 to action-1.jpg.
  - You can change any wording in index.html — each text has a Albanian
    (data-sq) and English (data-en) version side by side.
